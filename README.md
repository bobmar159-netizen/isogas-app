# IsoGas App

Aplicacion web estatica de dibujo isometrico para instalaciones de gas.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `isogas-app`.
2. Sube el contenido de esta carpeta a la raiz del repositorio.
3. Asegurate de que el archivo principal se llame `index.html`.
4. En GitHub, abre `Settings > Pages`.
5. En `Build and deployment`, elige:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
6. Guarda y espera unos minutos.
7. GitHub te dara una URL parecida a:
   - `https://TUUSUARIO.github.io/isogas-app/`

## Archivos

- `index.html`: app principal lista para publicar.

## Nota

La app esta pensada como archivo estatico unico, asi que GitHub Pages es suficiente para publicarla.
